# Hackathon archive

These are the papers I wrote when I first built Tukang Copilot for the Meta AI developer hackathon (Meta and Cerebral Valley, Oct to Nov 2026): the submission text and checklist, the judging map, the judge FAQ, the community vote and X post kits, the first 3-minute demo script and the original spec. The submission page had closed when I tried on 6 Nov 2026, so nothing was submitted, and Tukang Copilot is now my own project. I keep these files as they were on that day; their numbers and plans are from then and are not kept up to date.
